# Answer-first recall UX

FlashQuest should ask learners to commit to an answer before revealing the reference answer.

The expected flow is:

1. Read the challenge.
2. Enter an answer in the response field.
3. Ask for a hint if needed.
4. Reveal the reference answer.
5. Compare the entered answer with the reference answer.
6. Answer **Did you get it?** with **Missed it** or **Got it**.
7. Let spaced repetition/mastery scheduling use that self-rating.

The typed response is intentionally not exact-string auto-graded. Many valid answers can be phrased differently; the response field exists to force active recall before reveal while the learner remains responsible for the mastery rating.
